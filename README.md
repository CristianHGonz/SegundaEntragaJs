<b> Sección: Solicitar Servicio</b>
Esta sección contiene la mayor parte de la lógica de la aplicación:

Se creó un formulario para que el usuario ingrese sus datos. Si algún campo está incompleto o el formato es incorrecto, se muestra un aviso.

Al hacer clic en “Siguiente”, se presentan los planes disponibles. Solo se puede seleccionar un plan y se notifica al usuario si ha seleccionado o eliminado uno. Si no se selecciona ningún plan y se intenta avanzar, se muestra un aviso.

En la siguiente etapa, se muestran los datos del usuario y el plan seleccionado. El usuario debe ingresar un importe y aceptar las políticas para continuar; de lo contrario, se muestra un aviso en una ventana modal.

Una vez confirmados los datos, se guardan en localStorage y se envían por correo electrónico al usuario y al administrador utilizando la API EmailJS.

Tras unos segundos, la ventana modal se cierra y el usuario es redirigido a la página principal.
